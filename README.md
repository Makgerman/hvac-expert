# HVAC Expert — landing page / GitHub Pages

Статический адаптивный лендинг на **трёх языках**: английский (EN), русский (RU), сербский (SR, латиница). Без сборки, фреймворков, внешних библиотек и запросов к сторонним сервисам. Для публикации достаточно файлов из этой папки.

## Структура

```
index.html
.nojekyll
assets/
  app.js             # Языки, мобильное меню, карусель и управление фото
  content.js         # ВСЕ ТЕКСТЫ на EN, RU, SR
  images.js          # ЕДИНЫЙ СПИСОК изображений и их путей
  styles.css         # Дизайн и адаптивная верстка
  favicon.svg
  images/
    hero-hvac.webp
    inspection.webp
    vrf-diagnostics.webp
    ventilation.webp
    maintenance.webp
    controls.webp
    hydronic-systems.webp
    projects-engineering.webp
    engineer-01.webp ... engineer-04.webp    # Четыре портрета команды
    gallery-01.webp ... gallery-10.webp    # Десять снимков карусели
```

## Как заменить фото через GitHub

**Самый простой вариант — не менять код:**

1. Откройте в GitHub папку `assets/images/`.
2. Загрузите свою фотографию, подготовив её в WebP и дав **то же имя**, что у заменяемого изображения (например `hero-hvac.webp`). Подтвердите перезапись файла через новый коммит или удалите старый файл и загрузите новый.
3. Через несколько минут GitHub Pages покажет новое изображение. Если видно старое фото, обновите страницу с очисткой кеша.

**Если хотите другое имя файла:**

1. Загрузите фото, например `assets/images/sveti-stefan.webp`.
2. Откройте `assets/images.js` и замените соответствующий путь, например `hero: './assets/images/sveti-stefan.webp'`.
3. Для полного соответствия HTML (включая отображение без JavaScript) замените такой же `src` в `index.html`. Вариант с тем же именем файла предпочтительнее.

Соответствие имен разделам: `hero` — главное фото, `inspection` — обследование, `vrf` — ремонт VRV/VRF, `ventilation` — вентиляция, `maintenance` — обслуживание, `controls` — автоматика/пусконаладка, `hydronic` — вода/бассейны, `projects` — одно общее фото в разделе проектов. `engineer1`–`engineer4` — портреты команды; `gallery1`–`gallery10` — фотографии карусели.

## Фото сотрудников и карусель — быстрое редактирование

**Команда (4 карточки):** замените `assets/images/engineer-01.webp`, `engineer-02.webp`, `engineer-03.webp`, `engineer-04.webp` собственными фотографиями с теми же именами. Для аккуратного кадрирования подходят вертикальные портреты (примерно 700×800 px). Должность во всех языковых версиях указана как «Сервисный инженер»; при необходимости измените ключ `engineerRole` в `assets/content.js`. Карточки намеренно без выдуманных имен.

**Галерея (10 кадров):** замените `assets/images/gallery-01.webp` ... `gallery-10.webp`. Оптимально примерно 1120×820 px в WebP. Подписи к фотографиям (`galleryItem1` ... `galleryItem10`) и описания (`galleryAlt1` ... `galleryAlt10`) редактируются в `assets/content.js` отдельно для EN / RU / SR. Количество слайдов останется десять, управление стрелками и свайпами сохранится. Если требуется изменить именно число фотографий, потребуется соответствующее изменение `index.html`.

**Важно о временных фотографиях:** текущие четыре портрета были созданы для иллюстрации структуры сайта. Это не фотографии реальных сотрудников и не снимки из фотобанка. На опубликованном сайте под карточками специально указано, что портреты временные. Галерея также иллюстративная, пока вы не замените снимки на собственные. Все фотографии включены в архив, внешние сервисы не нужны.

**Советы по фотографиям:** лучше свои фотографии без персональных данных и без узнаваемых лиц заказчиков. Оптимально WebP: главный кадр около 1600–2000 px по ширине (до 300–450 КБ), кадры услуг 800–1200 px (обычно до 100–180 КБ). Текущие изображения — созданные специально для макета **иллюстративные изображения**, не документальные фотографии объектов HVAC Expert.

## Как изменить тексты и переводы

Все тексты собраны в `assets/content.js` в трёх словарях `en`, `ru`, `sr`. Например, найдите `heroTitle` и отредактируйте значение в каждом языке. Названия ключей и кавычки сохраняйте. `index.html` содержит английский текст в качестве исходного fallback; при обычном открытии переводы подменяются скриптом.

Язык выбирается в шапке; выбор сохраняется в браузере. Также можно открыть `?lang=ru`, `?lang=en` или `?lang=sr`, например `https://hvac-expert.me/?lang=sr`.

Телефон, почта, названия разделов и структура страниц — в `index.html`. Для изменения цвета, отступов и адаптивной верстки — `assets/styles.css`.

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub, например `hvac-expert-site`.
2. Загрузите **содержимое** этой папки в корень ветки `main`, чтобы `index.html` был в корне репозитория.
3. В `Settings → Pages → Build and deployment` выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите Save.
4. Адрес тестового сайта будет примерно `https://ВАШ-ЛОГИН.github.io/hvac-expert-site/`.
5. Для `hvac-expert.me`: в Pages укажите Custom domain, настройте DNS по инструкции GitHub. При необходимости создайте `CNAME` в корне репозитория с одной строкой `hvac-expert.me`, затем включите Enforce HTTPS.

**Важно:** на GitHub Pages нет обработки серверных форм. Ссылки `mailto:` и `tel:` работают без сервера. Номер и почта взяты из предоставленного резюме.

## Проверенные требования

- Адаптация под ширины 1440, 1024, 768, 390 и 320 px.
- Переключение EN / RU / SR и корректный `lang` в документе.
- Мобильное меню, скрытие меню после выбора раздела, включая пункт «Галерея».
- Карусель на 10 фотографий с кнопками «предыдущая/следующая», счётчиком и поддержкой свайпа/клавиатуры.
- Четыре карточки сервисных инженеров, адаптивные на мобильных экранах.
- Локальные изображения WebP без обращения к чужим CDN.
- Без горизонтального переполнения на проверенных размерах.
- Поддержка `prefers-reduced-motion`, skip-link, фокуса с клавиатуры, alt-описаний.
